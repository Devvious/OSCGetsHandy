Getting Started

  1. Purchase on Payhip — your license key arrives by email.
  2. Install and open Intiface Central, turn your toy on, and let it connect there first.
  3. Run OSCGetsHandy. Enter your license key and the email you purchased with.
  4. Click Start. Status should change to "Connected — [your device]".
  5. In VRChat: Action Menu → Options → OSC → Enable.
OSCGetsHandy advertises itself over OSCQuery, so VRChat finds it automatically — no manual port setup, and no conflicts if you're also running an app like VRCFT. If Status gets stuck on "No devices found," make sure Intiface shows your toy as connected before clicking Start.
Core

Active Sources

Controls which SPS parameters (PenOthers, TouchSelf, TouchOthers) the bridge listens to.

  1. Open the Active Sources page from the sidebar.
  2. Check/uncheck each source depending on what you want to trigger movement.
Enabling too many sources at once can cause them to fight over the toy's position. Start with one and add more only if needed.
Recommended for Solace

Predictive Movement

Compensates for hardware delay on toys like the Lovense Solace by learning your stroke pattern and sending it slightly ahead of time.

  1. Open Predictive Movement and enable it.
  2. Set Send Ahead — use the Calibrate Delay tool below to find your device's exact number, or check the Device Reference Sheet for a starting estimate.
  3. Adjust Size Tolerance and Speed Tolerance only if the prediction feels like it's "fighting" changes in your stroke pattern — higher tolerance adapts more slowly but stays smoother.
  4. The first couple of strokes always play normally while it learns — this is expected.
Recommended for Solace

Motor Kick-Start

Helps toys with slow motor acceleration (e.g. Solace) respond faster right after a direction change.

  1. Open Motor Kick-Start and enable it.
  2. Tune Burst Strength first — lower value = stronger kick.
  3. Burst Length is subtle and often barely noticeable — leave it at default unless you want to fine-tune further.
Leave this off for The Handy — it doesn't need it.
Optional

Boost

Stretches your current motion range outward — e.g. moving within 80–100% becomes 40–100%.

  1. Drag the Boost slider up from 1.0 (off) toward 3.0 (max stretch).
  2. It auto-calibrates to your actual current motion range, so you don't need to configure anything else.
Optional

Deadzone Limits

Hard-limits how far the toy is ever allowed to move.

  1. Open Deadzone Limits.
  2. Set Low limit and High limit — the stroker will never move outside this range.
Advanced

Source Mapping (Custom Sources)

Lets you add OSC addresses that aren't part of the default asset.

  1. Click Source Mapping to see every OSC address detected live.
  2. Click any listed address to add it automatically, or use + Add Source to paste one manually.
  3. Rename, reorder, or delete custom sources any time using the icons next to each entry.
Advanced

Universal Wildcard

Makes a built-in source (PenOthers/TouchSelf/TouchOthers) accept ANY tag name automatically, instead of only the default asset's exact tag.

  1. In Active Sources, check Universal Wildcard next to the source you want to make universal.
Caveat: if two different tags matching the same universal source are both active at once, whichever packet arrives most recently wins — this can cause jittery positioning. Only enable it if you're confident just one matching tag is realistically active at a time.
Optional

Jitter Filter

Ignores tiny movements caused by connection noise so the toy doesn't twitch on every packet.

  1. Enable Jitter Filter.
  2. Raise the Threshold slider until twitching stops — start low and increase gradually.
Situational

Invert Position

Flips the position output — use this only if your device is physically mounted or held upside down.

  1. Check Invert (device upside down) near the bottom of the settings window.
Troubleshooting

Run Diagnostics

A one-click self-check that tells you exactly what's wrong.

  1. Open Diagnostics from the sidebar.
  2. Each line shows ✓, ⚠, or ✕ with a plain-English explanation for anything failing.
  3. Click Run Again after making a change to re-check.
Advanced

Calibrate Delay

Measures your specific device's real-world delay for use with Predictive Movement.

  1. Turn off any continuously-running test signal first.
  2. Click Start Calibration.
  3. In the OSC Simulator, click Send Calibration Pulse.
  4. Tap the button in OSCGetsHandy the instant you feel the toy move.
  5. Repeat 3 times — the average is applied automatically to the Send Ahead slider.
Troubleshooting

Debug Log & Filters

Live technical log of everything the bridge is doing.

  1. Open Debug Log to view it inline, or click Pop Out for a separate window.
  2. Click Filters to hide categories you don't need (OSC IN, HANDY OUT, INTIFACE, LICENSE, etc).
  3. Use Pause to freeze scrolling while you read, and Clear Log to reset it.
Account

License & Devices

Each license key can be active on a limited number of devices at once.

  1. Menu bar → Help → About / License to check your activation status.
  2. If you've replaced or reinstalled a computer and hit your device limit, email Devviously@gmail.com to have a slot freed up.

Multi-Toy Support

Run more than one device at the same time — e.g. The Handy and a Lovense Solace together — each with its own independent settings and its own bar on the Live Position card.

Not released yet. This guide will fill in with exact steps once v3.0.0 ships — join the Discord for progress updates.
Coming in v3.0.0

Endpoint Snap

A per-device setting that snaps movement cleanly to the very top and bottom of your configured range, instead of trailing off.

Not released yet — will be overridable per device alongside Boost, Deadzone, Jitter, Invert, Predictive Movement and Kick-Start.
Coming in v3.0.0

Saved Presets

Save a full Predictive Movement setup (Send Ahead, tolerances) as a named preset per device, so switching toys doesn't mean re-tuning from scratch.

Coming in v3.0.0

First-Run Tutorial

A guided modal walkthrough for new users — including a sound-based source test with three chimes (hold still, interact, done) so headset wearers can find their correct source without needing to look at a screen. Skippable at any time, and replayable later from the Help menu.

Coming in v3.0.0

Hide/Show Features

A View menu listing every feature and source, with a checkmark next to the ones currently visible — so you can hide anything you don't use and bring it back later.
