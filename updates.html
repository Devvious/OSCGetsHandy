Updates & Planned Features

What's new, and what's coming next.
v2.0.4
Massive Update for Lovense Support — August 16, 2026
  • Predictive Movement — Learns your first 2 strokes, then sends a template ahead of time to your device so it feels like there's little to no delay. If your stroke changes too much, there will be a brief moment of de-sync. Two sliders control how quickly the template transitions toward new movement patterns.
  • Inside Predictive Movement, a Calibrate Delay button lets you figure out your device's delay using the simulator, or you can set it manually. The Lovense Solace tends to run about 1200–1500ms delay.
  • Saved Presets, for situations where you have multiple devices.
  • Motor Kick-Start — Starts every new stroke direction with a little extra power so the device doesn't feel sluggish. Makes movement snappier.
  • Source Mapping (under Active Sources) — Instead of manually digging through the debug log, this section lists off every source it comes across. Click a source and it's added to your Active Sources automatically.
  • Tweaks: UI reordering, Debug Log filters and pop-out window, and the OSC port number now shows in the Status section.
v2.0.3
Previous
  • Added custom OSC source support — enter an exact address, or a wildcard pattern for avatars with non-standard tag names.
  • Added a per-source Universal Wildcard toggle for the built-in PenOthers, TouchSelf, and TouchOthers sources.
  • Added Pause/Resume for the debug log, for easier copying without scroll interference.
  • Fixed duplicate-packet log spam by applying rounding and deduplication to all incoming OSC traffic, not just built-in sources.
  • Reduced OSC value rounding precision for smoother, less noisy updates.
