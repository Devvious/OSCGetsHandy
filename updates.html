Updates & Planned Features

What's new, and what's coming next.
v3.0.2
Predictive Movement Fixed — October 2026
  • Predictive Movement fixed — It was mixing each up-stroke with a down-stroke, which made the toy do short, jittery moves. It now learns up-strokes and down-strokes separately and plays your real stroke size and rhythm ahead of time. Strokes keep their full size, prediction starts from the moment your stroke really turns around, and it keeps moving smoothly even if VRChat goes quiet for a moment. Works best with steady, repeating strokes.
  • Predictive Movement and the Handy — The Handy reacts fast and doesn't need Predictive Movement. If a Handy connects while it's on, a pop-up asks if you'd like to turn it off.
  • Source Priority — When more than one source is active, the toy now follows only one instead of jumping between them (All PenOthers, then All TouchOthers, then All TouchSelf, then your custom sources from top to bottom). The Debug Log shows a "Now following" line when it switches.
  • More Than One Source warning — A pop-up now tells you it works best with just 1 source on when you press Start with several on, or turn on another source.
  • Collect All Debug Data is now on by default, and the whole session is saved to the log file as it happens. Nothing gets cut off, even if the app crashes. Save Log now saves the whole session.
  • Errors inside the app window are now written to the debug log, so problems like a menu not opening leave a trace.
  • The Troubleshooter now warns about running more than 1 source, and about Predictive Movement being on with a Handy.
v3.0.0
All-New Look & Multiple Toys — October 2026
  • Brand-new interface — Soft, bubbly and smooth, with a sidebar where every feature has its own page. The sidebar can collapse to a slim icon strip, and each page has a status bubble: green = On, red = Off.
  • Multiple Toys — Connect more than one toy at the same time. Give any extra toy its own settings and choose which sources move it. Every connected toy gets its own live position bar.
  • First-Run Tutorial — A short guided walkthrough on first launch. Skip it any time and replay it from Help.
  • Find Source (Auto) — Not sure which signal to use? Press Start Test and listen for 3 chimes (hold still, touch it, finished) and the app finds it for you, even with a headset on.
  • Calibrate Delay now uses the VRChat crouch toggle, so you never have to click a button with a headset on. PC only for now — try PCVR first.
  • Endpoint Snap — Positions near the very top or bottom are sent the whole way, so strokes actually reach the ends.
  • Troubleshooter (Help menu) checks your license, Intiface, your toy and what VRChat is sending, step by step, with the likely fix for anything wrong.
  • Export OSC Session Log, live "What it looks like" previews with Tip cards, drag-to-reorder custom sources, and the debug log is now saved automatically every time you close the app.
  • Fixed the license key generator tool freezing on the announcement step.
v2.0.7
Previous

v2.0.5
Previous
  • Macro Switch — Bind a VRChat avatar action to a function in the app, like turning Preset Strokes or Jitter Filter on and off, switching Character Profile, or raising and lowering Boost.
  • OSCGetsHandy now detects the avatar you already had loaded before launching, and has a Detect Current Avatar button.
  • New View menu to show or hide any section. Reorganize moved there too.
  • Source search now sorts likely sources first, and you can edit the keyword lists. New keywords in updates are offered to you without overwriting your own.
  • Parameter List can be sorted by name or by how often a value changes, and live values update without flashing.
  • Preset Stroking renamed to Preset Strokes, and a User Guide link added to the main window.
v2.0.4
Massive Update for Lovense Support — August 16, 2026
  • Predictive Movement — Learns your first 2 strokes, then sends a template ahead of time to your device so it feels like there's little to no delay. If your stroke changes too much, there will be a brief moment of de-sync. Two sliders control how quickly the template transitions toward new movement patterns.
  • Inside Predictive Movement, a Calibrate Delay button lets you figure out your device's delay using the simulator, or you can set it manually. The Lovense Solace tends to run about 1200–1500ms delay.
  • Saved Presets, for situations where you have multiple devices.
  • Motor Kick-Start — Starts every new stroke direction with a little extra power so the device doesn't feel sluggish. Makes movement snappier.
  • Source Mapping (under Active Sources) — Instead of manually digging through the debug log, this section lists off every source it comes across. Click a source and it's added to your Active Sources automatically.
  • Tweaks: UI reordering, Debug Log filters and pop-out window, and the OSC port number now shows in the Status section.
v2.0.3
Previous
  • Added custom OSC source support — enter an exact address, or a wildcard pattern for avatars with non-standard tag names.
  • Added a per-source Universal Wildcard toggle for the built-in PenOthers, TouchSelf, and TouchOthers sources.
  • Added Pause/Resume for the debug log, for easier copying without scroll interference.
  • Fixed duplicate-packet log spam by applying rounding and deduplication to all incoming OSC traffic, not just built-in sources.
  • Reduced OSC value rounding precision for smoother, less noisy updates.
